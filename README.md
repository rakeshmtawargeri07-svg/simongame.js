 Simon Game 
A simple and fun memory game built using HTML, CSS, JavaScript, and jQuery.
The game generates a random sequence of colours and sounds, and the player has to repeat the same pattern correctly to continue to the next level.

Features
* Random colour generation
* Button animations
* Sound effects for each button
* Level progression
* Game over detection

Technologies Used
* HTML
* CSS
* JavaScript
* jQuery

How to Play
1. Press any key to start the game.
2. Watch the colour sequence carefully.
3. Repeat the same sequence by clicking the buttons.
4. The sequence gets longer every round.
5. If you click the wrong button, the game ends and restarts.
